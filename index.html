Personal Drive

App name: Personal Drive. This page is public. No sign-in is required to read it.

Personal Drive is a desktop program used only by its owner, Nick Gu. Its purpose is to mount Nick Gu's own Google Drive on Nick Gu's own computer, so those existing files can be opened, saved, and synced between that computer and that Drive.

Personal Drive 是 Nick Gu 本人使用的桌面程序。用途只有一个：把本人的 Google Drive 挂到本人的电脑上，打开、保存并同步本人已有的文件。

The program requests access to Google Drive for that file sync. It does not offer sign-in to anyone else, and it does not send files to any other service.

Personal Drive does not use Google APIs to create, edit, or distribute images or video. It does not generate content with AI. It does not create or process non-consensual intimate imagery of real people, including AI-generated imagery (NCII).

Personal Drive 不使用 Google API 来创建、编辑或分发图片或视频，不用 AI 生成内容，也不会生成或处理未经当事人同意的私密图像，包括 AI 生成的此类图像（NCII）。
