Personal Drive privacy policy

This policy describes how Personal Drive, a desktop program used only by Nick Gu, collects and uses data. This page is public and does not require sign-in.

本政策说明 Personal Drive 如何收集和使用数据。此页公开，无需登录。

Who this applies to

Personal Drive is used only by Nick Gu to access Nick Gu's own Google Account. It is not offered to the public and does not create accounts for other people.

Data the app accesses

After Nick Gu grants permission, Personal Drive accesses Google Drive data through the Google Drive API:

  • File and folder names, identifiers, sizes, and modification times.
  • File contents, so those files can be downloaded to the computer and uploaded back to Drive.
  • The OAuth access token and refresh token that Google issues for this access.

Personal Drive does not request Gmail, Contacts, Calendar, Photos, or any other Google product. It does not read data from other people's accounts.

How that data is collected

Collection happens only after an OAuth consent on the computer where the program is installed. Google shows the consent screen, Nick Gu approves the Drive scope, and Google returns tokens to the program. The program then calls the Drive API to list, download, create, and update files that belong to that same Google Account.

How that data is used

Drive file metadata and file contents are used only to keep a copy of those files on Nick Gu's computer and to write changes from that computer back to Nick Gu's Drive. The refresh token is used only to obtain a new access token when the previous one expires, so the same sync can continue.

The data is not used for advertising, not sold, not used to train models, and not used to generate images, video, or text. Personal Drive does not use Google user data to create or process non-consensual intimate imagery of real people, including AI-generated imagery.

Where data is stored and who can see it

File contents remain in Google Drive and on the owner's computer. OAuth tokens are stored in the rclone configuration file on that computer. Personal Drive does not send Google user data to the developer of any other app, to an analytics service, or to any third party. No one other than Nick Gu operates this program.

Retention and deletion

Files stay in Drive until Nick Gu deletes them there, and on the computer until Nick Gu deletes the local copy. OAuth tokens stay in the local configuration until Nick Gu deletes that configuration or revokes the app. Revoking access at Google Account third-party access stops further collection. Tokens already stored on the computer are then deleted with the local configuration.

Contact

Nick Gu, the owner of Personal Drive and of this website, is the contact for this policy.
